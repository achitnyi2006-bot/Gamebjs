# NEON RUSH 3D

A mobile-friendly Three.js/WebGL arcade racing starter.

## Files
- `index.html` loads the game module.
- `style.css` provides the base page styles.
- `src/main.js` contains the 3D scene and gameplay.

## Run
Host the repository with GitHub Pages. The game needs internet access to load Three.js from unpkg.

## Controls
- Use left/right buttons or swipe to steer.
- Press BOOST for a temporary speed increase.
- Avoid traffic.

This is a procedural 3D starter, not a finished commercial game. Telegram Mini App and Adsgram integration are not included yet.
